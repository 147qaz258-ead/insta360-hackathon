# 摄影评审标准（Photography Critique Rubric）

评估每张候选照片时，按五层顺序进行自然语言评审。不要打机械化分数，要像图片编辑一样说出判断和理由。

## 第一层：照片到底想表达什么

- 这张照片的视觉主题是什么？
- 用户要求表达什么？
- 当前画面有没有清晰地表达这个意图？

选图不只是技术质量，而是图片是否传递信息、故事与视觉冲击力。

## 第二层：视觉组织

- 视觉中心是否清楚？
- 画面元素有没有互相竞争？
- 视觉重量是否平衡？
- 有没有前景—中景—背景形成空间层次？
- 道路、建筑、树木、阴影等有没有形成引导线？
- 负空间是否有意义？
- 对称或非对称是否服务于画面？
- 框架是否帮助聚焦？

## 第三层：边缘和背景

- 人后面是不是"长了一根电线杆"？
- 树或建筑是不是刚好被边缘切断？
- 背景有没有比主体更抢眼？
- 是否有元素贴着画框造成视觉紧张？

核心问题：这个元素是在帮助照片，还是在干扰照片？

## 第四层：光与颜色

- 光线是否支持场景情绪？
- 曝光是否合适，高光/阴影是否丢失重要信息？
- 色彩关系是否协调？
- 色彩是否让主体和环境产生分离？

## 第五层：技术问题（硬性淘汰项）

- 严重模糊、过曝、欠曝
- 明显拼接错误、鬼影
- 球面重投影畸变（直线异常弯曲，通常是 fov 过大或 pitch 极端）
- 明显噪点
- 重要内容被错误裁断

## 候选比较方式

比较多个候选时，不分别打分，而是直接做编辑判断：哪一张最符合用户意图并且在摄影上最完整？比较它们的视觉叙事、构图、光线、背景、裁切和技术问题，选择一张；如果没有一张达到要求，提出下一次取景方向。

## 评估输出（内部思考格式）

```
verdict: KEEP / REVISE / REJECT
intent_match: 当前画面与用户意图的匹配情况
strengths: [优点列表]
problems: [问题列表]
next_action: 如果 REVISE，下一步怎么调整（yaw/pitch/fov/画幅）及理由
```
